Recipe Builder UML Images

Full-resolution copies of the eight sprint 5 diagrams, for slides and for redrawing in a diagram tool. Click a diagram to open it full screen and zoom in.

Which file to use
  • SVG for PowerPoint. It stays sharp at any size. In PowerPoint, Insert → Pictures, choose the .svg. Right-click it → Convert to Shape to edit boxes and text.
  • PNG for Google Slides, Docs or anywhere SVG isn't accepted. It is 200 dpi, so it stays sharp when shrunk to fit a slide.
  • The SVG and PNG files are in the repo, in docs/uml/images/. Drag them from there into your slides.
